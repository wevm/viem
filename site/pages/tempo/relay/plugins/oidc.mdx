# OIDC Plugin

## Overview

[`Relay.oidc`](/tempo/relay/plugins/oidc#relayoidc) proves OIDC sign-ins for
[OIDC signing](/tempo/guides/oidc), and makes the relay a Relay API. It checks the ID token,
derives the user's salt from a secret salt key, and requests a proof from a prover service.
Unrelated requests pass to the next plugin or execution client.

## Recipes

Choose a local relay to run plugins in your application, or connect to a remote
relay. For remote mode, [configure the server](/tempo/guides/oidc/relay-api)
with the plugins shown in the local configuration.

### Prove a Sign-In

Prove a sign-in with [`oidc.prove`](/tempo/actions/oidc.prove). The relay returns the credential
that [`Account.fromZk`](/tempo/accounts/account.fromZk) signs with.

:::code-group

```ts twoslash [example.ts]
import { Account, WebCryptoP256 } from 'viem/tempo'
import { client } from './viem.config'

// Signs the user in with Google and returns the ID token for `nonce`.
declare function signInWithGoogle(options: { nonce: string }): Promise<string>

const keyPair = await WebCryptoP256.createKeyPair()

// [!code focus:start]
const { credential } = await client.oidc.prove({
  getToken: ({ nonce }) => signInWithGoogle({ nonce }),
  publicKey: keyPair.publicKey,
})
// [!code focus:end]

const account = Account.fromZk(credential)
```

```ts twoslash [viem.config.ts (Local Relay)] filename="viem.config.ts"
import { http } from 'viem'
import { createClient, Relay, withRelay } from 'viem/tempo'

export const client = createClient({
  transport: withRelay(http(), {
    plugins: [
      // [!code focus:start]
      Relay.oidc({
        audiences: ['1234567890-abc.apps.googleusercontent.com'],
        issuers: ['https://accounts.google.com'],
        prover: { apiKey: '...', url: 'https://prover.example.com' },
        publisherId: '0xa3c1274aadd82e4d12c8004c33fb244ca686dad4fcc8957fc5668588c11d9502',
        saltKey: '0x...',
      }),
      // [!code focus:end]
    ],
  }),
})
```

```ts twoslash [viem.config.ts (Remote Relay)] filename="viem.remote.config.ts"
import { http } from 'viem'
import { createClient } from 'viem/tempo'

// See https://viem.sh/tempo/guides/oidc/relay-api for instructions on running a Relay API.
export const client = createClient({
  transport: http('https://relay.example.com/rpc'), // [!code focus]
})
```

:::
Run the local configuration only in a trusted server environment, since the plugin holds the
salt key. The relay only proves sign-ins whose signing key the
[Key Publisher](/tempo/guides/oidc/publish-keys) lists, because the network rejects proofs for
other keys.

## `Relay.oidc`

Creates middleware that proves OIDC sign-ins. Other requests pass to the next plugin or execution client.

### Usage

```ts twoslash
import { Relay } from 'viem/tempo'

const plugin = Relay.oidc({
  audiences: ['1234567890-abc.apps.googleusercontent.com'],
  issuers: ['https://accounts.google.com'],
  prover: { apiKey: '...', url: 'https://prover.example.com' },
  publisherId: '0xa3c1274aadd82e4d12c8004c33fb244ca686dad4fcc8957fc5668588c11d9502',
  saltKey: '0x...',
})
```

### Parameters

#### options.audiences

- **Type:** `readonly string[]`

Accepted `aud` values: the OAuth client IDs of the apps the relay serves.

```ts twoslash
import { Relay } from 'viem/tempo'
// ---cut---
const plugin = Relay.oidc({
  audiences: ['1234567890-abc.apps.googleusercontent.com'], // [!code focus]
  issuers: ['https://accounts.google.com'],
  prover: { apiKey: '...', url: 'https://prover.example.com' },
  publisherId: '0x...',
  saltKey: '0x...',
})
```

#### options.fetch

- **Type:** `typeof fetch`
- **Default:** `globalThis.fetch`

Fetch for issuer keys and the prover, such as a Cloudflare service binding's.

```ts twoslash
import { Relay } from 'viem/tempo'
declare const env: { PROVER: { fetch: typeof fetch } }
// ---cut---
const plugin = Relay.oidc({
  audiences: ['1234567890-abc.apps.googleusercontent.com'],
  fetch: (input, init) => env.PROVER.fetch(input, init), // [!code focus]
  issuers: ['https://accounts.google.com'],
  prover: { apiKey: '...', url: 'https://prover.example.com' },
  publisherId: '0x...',
  saltKey: '0x...',
})
```

#### options.issuers

- **Type:** `readonly string[]`

Accepted `iss` values. The relay reads each issuer's signing keys from its discovery document.

```ts twoslash
import { Relay } from 'viem/tempo'
// ---cut---
const plugin = Relay.oidc({
  audiences: ['1234567890-abc.apps.googleusercontent.com'],
  issuers: ['https://accounts.google.com'], // [!code focus]
  prover: { apiKey: '...', url: 'https://prover.example.com' },
  publisherId: '0x...',
  saltKey: '0x...',
})
```

#### options.prover

- **Type:** `{ apiKey: string; url: string }`

The prover service and its bearer token.

```ts twoslash
import { Relay } from 'viem/tempo'
// ---cut---
const plugin = Relay.oidc({
  audiences: ['1234567890-abc.apps.googleusercontent.com'],
  issuers: ['https://accounts.google.com'],
  prover: { apiKey: '...', url: 'https://prover.example.com' }, // [!code focus]
  publisherId: '0x...',
  saltKey: '0x...',
})
```

#### options.publisherId

- **Type:** `Hex`

The Key Publisher whose key lists the identities trust. It is part of each identity's address, so changing it changes every address.

```ts twoslash
import { Relay } from 'viem/tempo'
// ---cut---
const plugin = Relay.oidc({
  audiences: ['1234567890-abc.apps.googleusercontent.com'],
  issuers: ['https://accounts.google.com'],
  prover: { apiKey: '...', url: 'https://prover.example.com' },
  publisherId: '0xa3c1274aadd82e4d12c8004c33fb244ca686dad4fcc8957fc5668588c11d9502', // [!code focus]
  saltKey: '0x...',
})
```

#### options.saltKey

- **Type:** `Hex`

The durable secret that derives identity salts. Losing it locks users out of their accounts, and
leaking it lets anyone link addresses to the identities that signed in.

```ts twoslash
import { Relay } from 'viem/tempo'
// ---cut---
const plugin = Relay.oidc({
  audiences: ['1234567890-abc.apps.googleusercontent.com'],
  issuers: ['https://accounts.google.com'],
  prover: { apiKey: '...', url: 'https://prover.example.com' },
  publisherId: '0x...',
  saltKey: '0x...', // [!code focus]
})
```

### Return Value

`Relay.Plugin`

A relay plugin that handles `oidc_prove`.

### Errors

| Error | Description |
| --- | --- |
| `RpcResponse.InvalidParamsError` | The request parameters are malformed. |
| `RpcResponse.InvalidInputError` | The ID token is not accepted: its issuer, audience, expiry, nonce, signature, or key listing fails, or the prover cannot prove it. |
| `RpcResponse.ResourceUnavailableError` | The prover is busy or starting. Retry the request. |
| `RpcResponse.InternalError` | The issuer's keys or the prover are unavailable, or the proof does not match the sign-in. |

## RPC Methods

### `oidc_prove`

Takes `{ accessKeyAddress, blinding, token, validUntil }`, with `validUntil` as a hex quantity, and returns the credential with hex quantities. The token's nonce must commit to the access key, blinding value, and `validUntil`, which must fall within 600 seconds after the token's `iat`.

The relay never logs or returns the token, blinding value, or salt.
