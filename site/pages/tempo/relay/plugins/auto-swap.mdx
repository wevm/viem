# Auto Swap Plugin

## Overview

[`Relay.autoSwap`](#relayautoswap) adds Stablecoin DEX swaps when a fill fails
with `InsufficientBalance`. It uses a token the sender holds to acquire the
missing amount, then retries the fill with approval and swap calls prepended.

## Recipes

Choose a local relay to run plugins in your application, or connect to a remote
relay at `/relay`. For remote mode, [configure the server](/tempo/guides/relay/run#add-plugins)
with the plugins shown in the local configuration.

### Fill a Transfer with Another Token

Combine Auto Swap with [`Relay.feeToken`](/tempo/relay/plugins/fee-token) to
select a held token and [`Relay.simulate`](/tempo/relay/plugins/simulate) to
preview the resulting balance changes.

:::code-group

```ts twoslash [example.ts]
import { parseUnits } from 'viem'
import { fillTransaction } from 'viem/actions'
import { Actions } from 'viem/tempo'
import { client } from './viem.config'

const { transaction, capabilities } = await fillTransaction(client, {
  account: '0x1111111111111111111111111111111111111111',
  calls: [Actions.token.transfer.call(client, {
    token: '0x20c000000000000000000000b9537d11c60e8b50', // USDC.e on Tempo mainnet
    to: '0x2222222222222222222222222222222222222222',
    amount: parseUnits('100', 6),
  })],
})

// [!code focus:start]
capabilities?.autoSwap
// @log: {
// @log:   calls: [
// @log:     { to: '0x20c0000000000000000000000000000000000000', data: '0x095ea7b3...' },
// @log:     { to: '0xdec0000000000000000000000000000000000000', data: '0x...' },
// @log:   ],
// @log:   maxIn: {
// @log:     decimals: 6, formatted: '105', name: 'PathUSD', symbol: 'pathUSD',
// @log:     token: '0x20c0000000000000000000000000000000000000', value: '0x6422c40',
// @log:   },
// @log:   minOut: {
// @log:     decimals: 6, formatted: '100', name: 'Bridged USDC (Stargate)', symbol: 'USDC.e',
// @log:     token: '0x20c000000000000000000000b9537d11c60e8b50', value: '0x5f5e100',
// @log:   },
// @log:   slippage: 0.05,
// @log: }
transaction.calls // Approval and DEX buy calls precede the requested transfer.
// [!code focus:end]
```

```ts twoslash [viem.config.ts (Local Relay)] filename="viem.config.ts"
import { http } from 'viem'
import { createClient, Relay, withRelay } from 'viem/tempo'

export const client = createClient({
  transport: withRelay(http(), {
    plugins: [
      Relay.simulate(),
      Relay.autoSwap({ slippage: 0.05 }), // [!code focus]
      Relay.feeToken(),
    ],
  }),
})
```

```ts twoslash [viem.config.ts (Remote Relay)] filename="viem.remote.config.ts"
import { http } from 'viem'
import { createClient, withRelay } from 'viem/tempo'

// See https://viem.sh/tempo/guides/relay/run for instructions on running a relay.
export const client = createClient({
  transport: withRelay(http(), http('/relay')), // [!code focus]
})
```

:::


This example assumes the sender has no USDC.e and holds enough pathUSD for
the swap and fees. The DEX needs liquidity. Calldata is abbreviated in the example
response; the returned `calls` contain complete calldata. The plugin reports injected calls, maximum input, minimum output, and
slippage in `capabilities.autoSwap`. Swap movements are excluded from the
simulation's transfer balance changes.

If swap metadata cannot be loaded, the
fill fails so injected calls are never returned without their swap disclosure.

Place `autoSwap` before `feeToken` so retries select a fee token again. For a local
sponsor, place `feePayer` before `autoSwap` to validate and sign the final candidate.
For an external fee-payer URL, place `autoSwap` before `feePayer` to retry that relay's
failed fills. Place `simulate` first to report the final calls after swaps.

## `Relay.autoSwap`

Creates a plugin that recovers missing token balances during transaction preparation.
It also attempts a swap when a successful fill selects a fee token with an
insufficient balance. Failure of that additional attempt preserves the original fill.

### Usage

```ts twoslash
import { Relay } from 'viem/tempo'

const plugin = Relay.autoSwap({ slippage: 0.02 })
```

### Parameters

#### options.slippage

- **Type:** `number`
- **Default:** `0.05`

Maximum additional source-token input as a fraction. For a deficit of 10 tokens,
`0.02` allows a maximum input of 10.2 tokens. This calculation assumes tokens
with equal nominal values and does not fetch a market-price quote.

```ts twoslash
import { Relay } from 'viem/tempo'
// ---cut---
Relay.autoSwap({ slippage: 0.02 }) // [!code focus]
```

#### options.store

- **Type:** `Store.Store`

Optional [store](/tempo/utilities/Store) for token metadata, cached for 24 hours.
Without a store, metadata is read for each request.

```ts twoslash
import { Relay, Store } from 'viem/tempo'
// ---cut---
Relay.autoSwap({ store: Store.memory() }) // [!code focus]
```

### Return Value

`Relay.Plugin`

A plugin for `Relay.create`, `Relay.handleRequest`, or local `withRelay`.

### Errors

| Error | Description |
| --- | --- |
| `RpcRequestError` | The fill or recovery swap fails, or no funded source token is available. |
