# `Account.fromMultisig`

Creates a native multisig account. Supply the recovery factory configured by the chain; there is no default production factory. The first transaction initializes the account, and every subsequent signature includes its complete current config.

## Usage

```ts twoslash
import { Account } from 'viem/tempo'

declare const factory: `0x${string}`
const owner = Account.fromSecp256k1(
  '0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80'
)
const account = Account.fromMultisig({ owners: [owner] }, { factory })
```

Owners may be addresses, local accounts, or `{ owner, weight }` entries. Local accounts can collect approvals automatically. Address-only owners sign the prepared request independently as shown in [Send Transactions](/tempo/guides/multisig/send).

Only secp256k1, P256, and WebAuthn owner signatures are supported. Nested multisig accounts and access keys cannot act as owners.

## Updated Configurations

Retain the original address and the complete updated config returned by [multisig.updateConfigSync](/tempo/actions/multisig.updateConfigSync). Reconstruct the account with that address:

```ts twoslash
import { Account, type MultisigConfig } from 'viem/tempo'

declare const factory: `0x${string}`
declare const address: `0x${string}`
declare const config: MultisigConfig.Config
const account = Account.fromMultisig(config, { factory, address })
```

Preparation checks the supplied config against the stored commitment. A stale config is rejected. `Account.fromMultisig(address)` creates an account without a config; supply `{ account: address, config }` in the request's `multisig` field before signing.

## Return Type

`MultisigAccount`: a local account with its normalized `config` and retained local `owners`. It supports `signTransaction`; direct `sign`, `signMessage`, and `signTypedData` are unsupported.

## Parameters

### config

The current owners and optional `threshold`, `salt`, and `version`. Threshold defaults to `1`, salt to 32 zero bytes, and version to `0n`. Owners are sorted by address.

### options.factory

`Address`: the recovery factory configured by the chain. Required when constructing from a config.

### options.address

`Address`: the stable account address. Supply this address when using an updated config. Without it, the address is derived from the version-zero config and factory.
