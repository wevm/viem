# `attested.getPolicy`

Gets an attested signer policy's roles and settings. Wallets show its delay, guardian, and key lifetime cap, which bound what its owner can do.

:::warning
Experimental. Attested signers ([TIP-1159](https://github.com/tempoxyz/tempo/pull/8822)) are a draft and are not active on any public Tempo network. This action targets the experimental node implementation, whose registry address differs from the TIP.
:::

## Usage

:::code-group

```ts twoslash [example.ts]
import { client } from './viem.config'

const policy = await client.attested.getPolicy({
  policyId: '0x...',
})
// @log: {
// @log:   delay: 86400,
// @log:   epoch: 0,
// @log:   guardian: '0x70997970C51812dc3A010C7d01b50e0d17dc79C8',
// @log:   maxKeyLifetime: 7200,
// @log:   owner: '0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266',
// @log:   paused: false,
// @log:   pendingDelay: 0,
// @log:   pendingDelayAt: 0,
// @log:   pendingMaxKeyLifetime: 0,
// @log:   pendingMaxKeyLifetimeAt: 0,
// @log:   scheme: 1,
// @log: }
```

## Return Value

`getPolicy.ReturnValue`

The policy. Its `owner` is the zero address if the policy does not exist. Durations are in seconds, and times in Unix seconds.

## Parameters

### policyId

- **Type:** `Hex`

Policy ID.
