# `fundingDiscovery.discover`

Finds currently available funding routes using supplied rules. Optionally verifies those rules against a stored funding policy. Discovery reserves no funds, so a later transaction can still fail if balances or liquidity change.

## Usage

:::code-group

```ts twoslash [example.ts]
import { Addresses, FundingSource } from 'viem/tempo'
import { client } from './viem.config'

const discovery = await client.fundingDiscovery.discover({
  account: client.account.address,
  amount: 50_000_000n,
  rules: {
    maxSlippageBps: 100,
    sources: {
      [Addresses.pathUsd]: [{
        target: Addresses.dexFundingSource,
        data: FundingSource.encodeData({ tokenIn: Addresses.alphaUsd }),
      }],
    },
  },
  token: Addresses.pathUsd,
})
// @log: { token: '0x...', amount: 50000000n, sources: [{ to: '0x...', data: '0x...', availableAmount: 50000000n }] }
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
// [!include ~/snippets/tempo/viem.config.ts:setup]
```

:::

For owner-authorized funding, pass `requireFunds: [discovery]` to a Tempo transaction. The transaction encoder uses each source's `to` and `data`; `availableAmount` is advisory and is not signed or sent.

## Return Type

```ts
type ReturnType = {
  token: Address
  amount: bigint
  slippageBps: number
  sources: {
    to: Address
    data: Hex
    availableAmount: bigint
  }[]
}
```

## Parameters

### account

- **Type:** `Address`

Account whose inputs are inspected.

### amount

- **Type:** `bigint`

Target output balance in token base units.

### policyId (optional)

- **Type:** `bigint`

Funding policy ID whose current commitment must match the supplied rules. Omit it to discover without reading a stored policy.

### rules

- **Type:** `Hex | FundingPolicy.Rules`

Complete rules specifying routes and maximum slippage, as an object or canonical ABI-encoded bytes. Objects are encoded automatically. When `policyId` is supplied, the rules must match the policy's current hash.

### token

- **Type:** `Address`

Required output token.
