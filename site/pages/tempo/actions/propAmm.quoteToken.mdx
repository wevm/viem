# `propAmm.quoteToken`

Reads the quote token of a propAMM pool.

## Usage

### Standalone Action

:::code-group

```ts twoslash [example.ts]
import { client } from './viem.config'

const quote = await client.propAmm.quoteToken({
  pool: '0x0000000000000000000000000000000000000002',
})
// @log: '0x0000000000000000000000000000000000000002'
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
// [!include ~/snippets/tempo/viem.config.ts:setup]
```

:::

## Return Value

```ts
type ReturnValue = Address
```

The token received when the pool swaps base for quote.

## Parameters

### pool

- **Type:** `Address`

Address of the propAMM pool.
