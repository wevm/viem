# `multisig.updateConfig`

Replaces the current owners and threshold for a native multisig account.

The transaction must be authorized by the current owner quorum. This direct action is useful when
the account retains enough local owners to sign. For distributed signing, include
`multisig.updateConfig.call` in a prepared request and collect approvals as shown in
[Rotate Multisig Owners](/tempo/guides/multisig/rotate-owners).

:::warning
The multisig account must already be initialized. The protocol does not allow initialization and
a configuration update in the same transaction.
:::

## Usage

:::code-group

```ts twoslash [example.ts]
import { Account } from 'viem/tempo'
import { client } from './viem.config'

const owner_1 = Account.fromSecp256k1(
  '0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80'
)
const owner_2 = Account.fromSecp256k1(
  '0x59c6995e998f97a5a0044966f0945389dc9e86dae88c7a8412f4603b6b78690d'
)
const newOwner = Account.fromSecp256k1(
  '0x5de4111afa1a4b94908f83103eb1f1706367c2e68ca870fc3fb9a804cdab365a'
)
const account = Account.fromMultisig({
  address: 'initial',
  owners: [owner_1, owner_2],
  threshold: 2,
})

const hash = await client.multisig.updateConfig({
  account,
  owners: [{ owner: newOwner.address, weight: 1 }],
  threshold: 1,
})
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
// [!include ~/snippets/tempo/viem.config.ts:setup]
```

:::

## Return Type

```ts
type ReturnType = Hash
```

The transaction hash.

## Parameters

### owners

- **Type:** `readonly { owner: Address; weight: number }[]`

The complete replacement owner set. Owners are normalized into canonical address order.

### threshold

- **Type:** `number`

The replacement approval weight required to authorize the account.
