# `accounts.upgrade`

Upgrades an existing account to a configurable account in place
([TIP-1113](https://tips.sh/1113)). The account keeps its address and installs the given owners and
threshold.

The account's root key must sign the upgrade, and the upgrade must be the transaction's only call.
After the upgrade, the root key can no longer sign for the account. Use
[`accounts.upgradeSync`](/tempo/actions/accounts.upgradeSync) to wait for confirmation.

## Usage

:::code-group

```ts twoslash [example.ts]
import { Account } from 'viem/tempo'
import { client } from './viem.config'

const root = Account.fromSecp256k1(
  '0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80'
)
const owner = Account.fromSecp256k1(
  '0x59c6995e998f97a5a0044966f0945389dc9e86dae88c7a8412f4603b6b78690d'
)

const hash = await client.accounts.upgrade({
  account: root,
  owners: [{ owner: owner.address, weight: 1 }],
  threshold: 1,
})
// @log: '0x...'
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
// [!include ~/snippets/tempo/viem.config.ts:setup]
```

:::

:::warning
Retiring the root key is permanent. Access key grants, permits, and channel vouchers that the root
key signs stop working after the upgrade.
:::

## Return Value

`Hash`

The transaction hash.

## Parameters

### owners

- **Type:** `readonly { owner: Address; weight: number }[]`

The owners to install. Owners are normalized into canonical address order, and must use
primitive signatures.

```ts twoslash
import { Account, createClient } from 'viem/tempo'

const client = createClient({ account: Account.fromSecp256k1('0x...') })
// ---cut---
await client.accounts.upgrade({
  owners: [{ owner: '0x...', weight: 1 }], // [!code focus]
  threshold: 1,
})
```

### threshold

- **Type:** `number`

The approval weight required to authorize the upgraded account.

```ts twoslash
import { Account, createClient } from 'viem/tempo'

const client = createClient({ account: Account.fromSecp256k1('0x...') })
// ---cut---
await client.accounts.upgrade({
  owners: [{ owner: '0x...', weight: 1 }],
  threshold: 1, // [!code focus]
})
```
