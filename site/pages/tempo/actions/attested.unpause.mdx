# `attested.unpause`

Unpauses an attested signer policy. The policy owner calls it.

:::warning
Experimental. Attested signers ([TIP-1159](https://github.com/tempoxyz/tempo/pull/8822)) are a draft and are not active on any public Tempo network. This action targets the experimental node implementation, whose registry address differs from the TIP.
:::

## Usage

:::code-group

```ts twoslash [example.ts]
import { client } from './viem.config'

const { receipt } = await client.attested.unpauseSync({
  policyId: '0x...',
})

console.log('Transaction hash:', receipt.transactionHash)
// @log: Transaction hash: 0x1234567890abcdef1234567890abcdef1234567890abcdef1234567890abcdef
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
// [!include ~/snippets/tempo/viem.config.ts:setup]
```

:::

### Asynchronous Usage

`attested.unpauseSync` waits for the transaction to be included. To wait for inclusion yourself, use `attested.unpause`, which returns the transaction hash:

```ts twoslash
import { client } from './viem.config'

const hash = await client.attested.unpause({
  policyId: '0x...',
})
const receipt = await client.waitForTransactionReceipt({ hash })
```

## Return Value

### unpause

`Hash`

The transaction hash.

### unpauseSync

```ts
type ReturnType = {
  /** Policy ID. */
  policyId: Hex
  /** Whether the policy is paused. */
  paused: boolean
  /** Transaction receipt. */
  receipt: TransactionReceipt
}
```

The `PolicyPaused` event's arguments and the transaction receipt.

## Parameters

### policyId

- **Type:** `Hex`

Policy ID.

### throwOnReceiptRevert (optional)

- **Type:** `boolean`
- **Default:** `true`

Whether `unpauseSync` throws if the transaction reverts. `unpauseSync` only.
