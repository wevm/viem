# `multisig.isInitialized`

Checks whether an address has initialized its native multisig configuration.

## Usage

:::code-group

```ts twoslash [example.ts]
import { client } from './viem.config'

const initialized = await client.multisig.isInitialized({
  account: '0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266',
})
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
// [!include ~/snippets/tempo/viem.config.ts:setup]
```

:::

## Return Type

```ts
type ReturnType = boolean
```

## Parameters

### account

- **Type:** `Address`

The derived multisig account address to check.
