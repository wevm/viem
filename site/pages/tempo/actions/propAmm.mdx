# PropAMM Actions

## Overview

A propAMM pool trades one fixed base and quote token pair at an oracle-bound price. Callers and recipients must satisfy the pool's allowlists. Pass the deployed pool address to each action.

Use [`getSwapQuote`](/tempo/actions/propAmm.getSwapQuote) with `mode: 'exactInput'` or `mode: 'exactOutput'` to price a customer route. The quote returns the oracle price and observation time needed by the swap. A quote does not reserve inventory or establish that the sender has enough input tokens.

[`swap`](/tempo/actions/propAmm.swap) and [`swapSync`](/tempo/actions/propAmm.swap) read the pool's input token and batch an approval with the swap in one Tempo transaction. The [`swap.call`](/tempo/actions/propAmm.swap) builder defines only the raw contract call, so add an approval when composing calls manually. The pool pulls input tokens from the transaction sender and sends output to `recipient`.

A pool's `baseToQuote` direction sends base when `true` and quote when `false`. Read [`baseToken`](/tempo/actions/propAmm.baseToken) and [`quoteToken`](/tempo/actions/propAmm.quoteToken) to identify the tokens. Keep the customer ID, price limit, deadline, and oracle binding explicit for each trade.

## Pool and Permission Reads

- [`baseToken`](/tempo/actions/propAmm.baseToken) and [`quoteToken`](/tempo/actions/propAmm.quoteToken) identify the pool's pair.
- [`paused`](/tempo/actions/propAmm.paused) checks whether swaps are paused.
- [`takerAllowed`](/tempo/actions/propAmm.takerAllowed) checks the caller's permission.
- [`resolveRecipient`](/tempo/actions/propAmm.resolveRecipient) and [`recipientAllowed`](/tempo/actions/propAmm.recipientAllowed) check the output destination.

See [Swap with a PropAMM Pool](/tempo/guides/propamm/swap) for a quote and swap example.
