# `funding.policyExists`

Checks whether a funding policy ID exists.

## Usage

:::code-group

```ts twoslash [example.ts]
import { client } from './viem.config'

const exists = await client.funding.policyExists({ policyId: 1n })
// @log: true
```


### Standalone Action

:::code-group

