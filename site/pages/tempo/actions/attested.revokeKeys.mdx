# `attested.revokeKeys`

Revokes every program key of an attested signer policy. Approved signer programs register new keys afterwards. The policy owner or guardian calls it.

:::warning
Experimental. Attested signers ([TIP-1159](https://github.com/tempoxyz/tempo/pull/8822)) are a draft and are not active on any public Tempo network. This action targets the experimental node implementation, whose registry address differs from the TIP.
:::

## Usage

:::code-group

```ts twoslash [example.ts]
import { client } from './viem.config'

const { receipt } = await client.attested.revokeKeysSync({
  policyId: '0x...',
})

console.log('Transaction hash:', receipt.transactionHash)
// @log: Transaction hash: 0x1234567890abcdef1234567890abcdef1234567890abcdef1234567890abcdef
```


:::

### Asynchronous Usage

`attested.revokeKeysSync` waits for the transaction to be included. To wait for inclusion yourself, use `attested.revokeKeys`, which returns the transaction hash:

```ts twoslash
import { client } from './viem.config'

const hash = await client.attested.revokeKeys({
  policyId: '0x...',
})
const receipt = await client.waitForTransactionReceipt({ hash })
```

## Return Value

### revokeKeys

`Hash`

The transaction hash.

### revokeKeysSync

```ts
type ReturnType = {
  /** Policy ID. */
  policyId: Hex
  /** The policy's new epoch. */
  epoch: bigint
  /** Transaction receipt. */
  receipt: TransactionReceipt
}
```

The `KeysRevoked` event's arguments and the transaction receipt.

## Parameters

### policyId

- **Type:** `Hex`

Policy ID.

### throwOnReceiptRevert (optional)

- **Type:** `boolean`
- **Default:** `true`

Whether `revokeKeysSync` throws if the transaction reverts. `revokeKeysSync` only.
