# `keyPublisher.isKeyActive`

Checks whether ZK signatures may use a key in the current block.

Listed keys are active, and so are keys in the grace period after [`keyPublisher.setKeys`](/tempo/actions/keyPublisher.setKeys) drops them. Revoked keys are inactive immediately.

## Usage

:::code-group

```ts twoslash [example.ts]
import { Oidc } from 'viem/tempo'
import { client } from './viem.config'

const active = await client.keyPublisher.isKeyActive({
  issuer: Oidc.hashIssuer('https://accounts.google.com'),
  keyHash: '0x0d6f3c1b2a9e8f7d6c5b4a39281706f5e4d3c2b1a09f8e7d6c5b4a3928170605',
  publisherId: '0xa3c1274aadd82e4d12c8004c33fb244ca686dad4fcc8957fc5668588c11d9502',
})

console.log(active)
// @log: true
```


:::

### Standalone Action

Call the action from `Actions` to pass the Client explicitly.

```ts twoslash
import { Actions, Oidc } from 'viem/tempo'
import { client } from './viem.config'

const active = await Actions.keyPublisher.isKeyActive(client, {
  issuer: Oidc.hashIssuer('https://accounts.google.com'),
  keyHash: '0x0d6f3c1b2a9e8f7d6c5b4a39281706f5e4d3c2b1a09f8e7d6c5b4a3928170605',
  publisherId: '0xa3c1274aadd82e4d12c8004c33fb244ca686dad4fcc8957fc5668588c11d9502',
})
```

## Return Value

`boolean`

Whether the key is active.

## Parameters

### issuer

- **Type:** `Hex`

Issuer hash, from `Oidc.hashIssuer`.

```ts twoslash
import { Oidc } from 'viem/tempo'
import { client } from './viem.config'
// ---cut---
await client.keyPublisher.isKeyActive({
  issuer: Oidc.hashIssuer('https://accounts.google.com'), // [!code focus]
  keyHash: '0x0d6f3c1b2a9e8f7d6c5b4a39281706f5e4d3c2b1a09f8e7d6c5b4a3928170605',
  publisherId: '0xa3c1274aadd82e4d12c8004c33fb244ca686dad4fcc8957fc5668588c11d9502',
})
```

### keyHash

- **Type:** `Hex`

Key hash, from `Oidc.hashKey` or `Oidc.fromJwk`.

```ts twoslash
import { Oidc } from 'viem/tempo'
import { client } from './viem.config'
// ---cut---
await client.keyPublisher.isKeyActive({
  issuer: Oidc.hashIssuer('https://accounts.google.com'),
  keyHash: '0x0d6f3c1b2a9e8f7d6c5b4a39281706f5e4d3c2b1a09f8e7d6c5b4a3928170605', // [!code focus]
  publisherId: '0xa3c1274aadd82e4d12c8004c33fb244ca686dad4fcc8957fc5668588c11d9502',
})
```

### publisherId

- **Type:** `Hex`

Publisher ID, from [`keyPublisher.create`](/tempo/actions/keyPublisher.create) or `PublisherId.from`.

```ts twoslash
import { Oidc } from 'viem/tempo'
import { client } from './viem.config'
// ---cut---
await client.keyPublisher.isKeyActive({
  issuer: Oidc.hashIssuer('https://accounts.google.com'),
  keyHash: '0x0d6f3c1b2a9e8f7d6c5b4a39281706f5e4d3c2b1a09f8e7d6c5b4a3928170605',
  publisherId: '0xa3c1274aadd82e4d12c8004c33fb244ca686dad4fcc8957fc5668588c11d9502', // [!code focus]
})
```
