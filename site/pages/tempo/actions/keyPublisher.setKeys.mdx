# `keyPublisher.setKeys`

Replaces the key hashes a publisher lists for an issuer. Previously listed keys that are left out stay valid for a one-hour grace period, so sign-ins in progress survive a rotation.

Viem sorts key hashes and drops repeats, so they may be passed in any order. Only the publisher's owner can set keys.

## Usage

:::code-group

```ts twoslash [example.ts]
import { Oidc } from 'viem/tempo'
import { client } from './viem.config'

const { graceUntil, keyHashes } = await client.keyPublisher.setKeysSync({
  issuer: Oidc.hashIssuer('https://accounts.google.com'),
  keyHashes: [
    '0x0d6f3c1b2a9e8f7d6c5b4a39281706f5e4d3c2b1a09f8e7d6c5b4a3928170605',
    '0x1b7e5d4c3a2f1e0d9c8b7a69584736251403f2e1d0c9b8a7968574635241302f',
  ],
  publisherId: '0xa3c1274aadd82e4d12c8004c33fb244ca686dad4fcc8957fc5668588c11d9502',
})

console.log('Grace until:', graceUntil)
// @log: Grace until: 1767229200n
```

### Standalone Action

Call the action from `Actions` to pass the Client explicitly.

```ts twoslash
import { Actions, Oidc } from 'viem/tempo'
import { client } from './viem.config'

const { graceUntil, keyHashes } = await Actions.keyPublisher.setKeysSync(client, {
  issuer: Oidc.hashIssuer('https://accounts.google.com'),
  keyHashes: [
    '0x0d6f3c1b2a9e8f7d6c5b4a39281706f5e4d3c2b1a09f8e7d6c5b4a3928170605',
    '0x1b7e5d4c3a2f1e0d9c8b7a69584736251403f2e1d0c9b8a7968574635241302f',
  ],
  publisherId: '0xa3c1274aadd82e4d12c8004c33fb244ca686dad4fcc8957fc5668588c11d9502',
})
```

### Asynchronous Usage

The example above uses a `*Sync` variant of the action, which waits for the transaction to be included before returning.

If you are optimizing for performance, use the non-sync `keyPublisher.setKeys` action and wait for inclusion manually:

```ts twoslash
import { Actions, Oidc } from 'viem/tempo'
import { client } from './viem.config'

const hash = await client.keyPublisher.setKeys({
  issuer: Oidc.hashIssuer('https://accounts.google.com'),
  keyHashes: [
    '0x0d6f3c1b2a9e8f7d6c5b4a39281706f5e4d3c2b1a09f8e7d6c5b4a3928170605',
    '0x1b7e5d4c3a2f1e0d9c8b7a69584736251403f2e1d0c9b8a7968574635241302f',
  ],
  publisherId: '0xa3c1274aadd82e4d12c8004c33fb244ca686dad4fcc8957fc5668588c11d9502',
})
const receipt = await client.waitForTransactionReceipt({ hash })

const { args } = Actions.keyPublisher.setKeys.extractEvent(receipt.logs)
```

## Recipes

These recipes assume you have [set up a Tempo client](/tempo).

### Follow an Issuer's Key Rotation

Issuers rotate their signing keys on their own schedule. Read the current JSON Web Key Set on an interval and replace the list.

```ts twoslash
import { Oidc } from 'viem/tempo'
import { client } from './viem.config'

const response = await fetch('https://www.googleapis.com/oauth2/v3/certs')
const { keys } = (await response.json()) as { keys: Oidc.fromJwk.Jwk[] }

await client.keyPublisher.setKeysSync({
  issuer: Oidc.hashIssuer('https://accounts.google.com'),
  keyHashes: keys.map((jwk) => Oidc.fromJwk(jwk).keyHash), // [!code focus]
  publisherId: '0xa3c1274aadd82e4d12c8004c33fb244ca686dad4fcc8957fc5668588c11d9502',
})
```

### Stop Listing an Issuer

Pass an empty list. The issuer's keys stay valid until `graceUntil`; revoke them with [`keyPublisher.revokeKey`](/tempo/actions/keyPublisher.revokeKey) to end them sooner.

```ts twoslash
import { Oidc } from 'viem/tempo'
import { client } from './viem.config'

await client.keyPublisher.setKeysSync({
  issuer: Oidc.hashIssuer('https://accounts.google.com'),
  keyHashes: [], // [!code focus]
  publisherId: '0xa3c1274aadd82e4d12c8004c33fb244ca686dad4fcc8957fc5668588c11d9502',
})
```

## Return Value

`{ graceUntil: bigint; issuer: Hex; keyHashes: readonly Hex[]; publisherId: Hex; receipt: TransactionReceipt }`

The `KeysSet` event fields and the transaction receipt. `graceUntil` is when the dropped keys stop being valid. `keyPublisher.setKeys` returns the transaction hash instead.

## Parameters

### issuer

- **Type:** `Hex`

Issuer hash, from `Oidc.hashIssuer`.

```ts twoslash
import { Oidc } from 'viem/tempo'
import { client } from './viem.config'
// ---cut---
await client.keyPublisher.setKeysSync({
  issuer: Oidc.hashIssuer('https://accounts.google.com'), // [!code focus]
  keyHashes: [
    '0x0d6f3c1b2a9e8f7d6c5b4a39281706f5e4d3c2b1a09f8e7d6c5b4a3928170605',
    '0x1b7e5d4c3a2f1e0d9c8b7a69584736251403f2e1d0c9b8a7968574635241302f',
  ],
  publisherId: '0xa3c1274aadd82e4d12c8004c33fb244ca686dad4fcc8957fc5668588c11d9502',
})
```

### keyHashes

- **Type:** `readonly Hex[]`

Key hashes to list for the issuer, in any order, from `Oidc.hashKey` or `Oidc.fromJwk`. Replaces the current list; at most 16 key hashes.

```ts twoslash
import { Oidc } from 'viem/tempo'
import { client } from './viem.config'
// ---cut---
await client.keyPublisher.setKeysSync({
  issuer: Oidc.hashIssuer('https://accounts.google.com'),
  keyHashes: [ // [!code focus]
    '0x0d6f3c1b2a9e8f7d6c5b4a39281706f5e4d3c2b1a09f8e7d6c5b4a3928170605', // [!code focus]
    '0x1b7e5d4c3a2f1e0d9c8b7a69584736251403f2e1d0c9b8a7968574635241302f', // [!code focus]
  ], // [!code focus]
  publisherId: '0xa3c1274aadd82e4d12c8004c33fb244ca686dad4fcc8957fc5668588c11d9502',
})
```

### publisherId

- **Type:** `Hex`

Publisher ID, from [`keyPublisher.create`](/tempo/actions/keyPublisher.create) or `PublisherId.from`.

```ts twoslash
import { Oidc } from 'viem/tempo'
import { client } from './viem.config'
// ---cut---

  issuer: Oidc.hashIssuer('https://accounts.google.com'),

    '0x0d6f3c1b2a9e8f7d6c5b4a39281706f5e4d3c2b1a09f8e7d6c5b4a3928170605',
    '0x1b7e5d4c3a2f1e0d9c8b7a69584736251403f2e1d0c9b8a7968574635241302f',
  ],
  publisherId: '0xa3c1274aadd82e4d12c8004c33fb244ca686dad4fcc8957fc5668588c11d9502', // [!code focus]

```

## Errors

Key Publisher reverts surface as a `ContractFunctionRevertedError` whose `data.errorName` is one of:

| Error | Description |
| --- | --- |
| `InvalidFieldElement` | An issuer or key hash is zero or not below the BN254 scalar field modulus. |
| `TooManyKeys` | An issuer lists more than 16 key hashes. |
| `Unauthorized` | The sender does not own the publisher. |
| `UnknownPublisher` | The publisher does not exist. |
