# `attested.registerKey`

Registers a program key into a key slot of an attested signer policy from an attestation document. The write ends the key the slot held. Anyone can call it, because the document authenticates itself.

:::warning
Experimental. Attested signers ([TIP-1159](https://github.com/tempoxyz/tempo/pull/8822)) are a draft and are not active on any public Tempo network. This action targets the experimental node implementation, whose registry address differs from the TIP.
:::

## Usage

:::code-group

```ts twoslash [example.ts]
import { client } from './viem.config'

const { receipt } = await client.attested.registerKeySync({
  policyId: '0x...',
  slot: 0,
  document: '0x...',
  programKey: '0x04...',
  lifetime: 7_200,
})

console.log('Transaction hash:', receipt.transactionHash)
// @log: Transaction hash: 0x1234567890abcdef1234567890abcdef1234567890abcdef1234567890abcdef
```


:::

### Asynchronous Usage

`attested.registerKeySync` waits for the transaction to be included. To wait for inclusion yourself, use `attested.registerKey`, which returns the transaction hash:

```ts twoslash
import { client } from './viem.config'

const hash = await client.attested.registerKey({
  policyId: '0x...',
  slot: 0,
  document: '0x...',
  programKey: '0x04...',
  lifetime: 7_200,
})
const receipt = await client.waitForTransactionReceipt({ hash })
```

## Return Value

### registerKey

`Hash`

The transaction hash.

### registerKeySync

```ts
type ReturnType = {
  /** Policy ID. */
  policyId: Hex
  /** `keccak256(policyId || x || y)` of the program key. */
  keyId: Hex
  /** Measurement of the signer program that holds the key. */
  measurement: Hex
  /** Key slot. */
  slot: number
  /** When the registration expires, in Unix seconds. */
  validUntil: bigint
  /** Transaction receipt. */
  receipt: TransactionReceipt
}
```

The `KeyRegistered` event's arguments and the transaction receipt.

## Parameters

### document

- **Type:** `Hex`

Attestation document, in the policy scheme's format. Its binding names the chain, registry, policy, slot, program key, and lifetime.

### lifetime (optional)

- **Type:** `number`
- **Default:** `0`

Requested seconds until the registration expires, capped by the policy's `maxKeyLifetime`. `0` requests the cap. It must match the lifetime the document binds.

### policyId

- **Type:** `Hex`

Policy ID.

### programKey

- **Type:** `Hex`

Program key: the uncompressed P256 public key that the signer program generated, with or without the `0x04` prefix.

### slot

- **Type:** `number`

Key slot to write, below 8. A signer program alternates between two slots, so its previous key stays current while a new one registers.

### throwOnReceiptRevert (optional)

- **Type:** `boolean`
- **Default:** `true`

Whether `registerKeySync` throws if the transaction reverts. `registerKeySync` only.
