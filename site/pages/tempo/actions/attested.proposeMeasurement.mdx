# `attested.proposeMeasurement`

Proposes a measurement for an attested signer policy. It becomes active after the policy's delay. The policy owner calls it.

:::warning
Experimental. Attested signers ([TIP-1159](https://github.com/tempoxyz/tempo/pull/8822)) are a draft and are not active on any public Tempo network. This action targets the experimental node implementation, whose registry address differs from the TIP.
:::

## Usage

:::code-group

```ts twoslash [example.ts]
import { client } from './viem.config'

const { receipt } = await client.attested.proposeMeasurementSync({
  policyId: '0x...',
  measurement: '0x...',
})

console.log('Transaction hash:', receipt.transactionHash)
// @log: Transaction hash: 0x1234567890abcdef1234567890abcdef1234567890abcdef1234567890abcdef
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
// [!include ~/snippets/tempo/viem.config.ts:setup]
```

:::

### Asynchronous Usage

`attested.proposeMeasurementSync` waits for the transaction to be included. To wait for inclusion yourself, use `attested.proposeMeasurement`, which returns the transaction hash:

```ts twoslash
import { client } from './viem.config'

const hash = await client.attested.proposeMeasurement({
  policyId: '0x...',
  measurement: '0x...',
})
const receipt = await client.waitForTransactionReceipt({ hash })
```

## Return Value

### proposeMeasurement

`Hash`

The transaction hash.

### proposeMeasurementSync

```ts
type ReturnType = {
  /** Policy ID. */
  policyId: Hex
  /** Proposed measurement. */
  measurement: Hex
  /** When the measurement becomes active, in Unix seconds. */
  activeAt: bigint
  /** Transaction receipt. */
  receipt: TransactionReceipt
}
```

The `MeasurementProposed` event's arguments and the transaction receipt.

## Parameters

### measurement

- **Type:** `Hex`

Measurement of the signer program to approve.

### policyId

- **Type:** `Hex`

Policy ID.

### throwOnReceiptRevert (optional)

- **Type:** `boolean`
- **Default:** `true`

Whether `proposeMeasurementSync` throws if the transaction reverts. `proposeMeasurementSync` only.
