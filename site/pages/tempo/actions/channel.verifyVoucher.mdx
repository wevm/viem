# `channel.verifyVoucher`

Verifies a TIP-20 channel reserve voucher signature.

Returns whether `signature` is a valid voucher for `cumulativeAmount` from the channel's voucher signer: its `authorizedSigner` when set, else the payer. It does not check `cumulativeAmount` against the channel's deposit or settled amount, so a valid voucher can still fail to settle. Use [`channel.getStates`](/tempo/actions/channel.getStates) to read the deposit and settled amount.

## Usage

:::code-group

```ts twoslash [example.ts]
import { parseUnits } from 'viem'
import { client, channel } from './viem.config'

const valid = await client.channel.verifyVoucher({
  channel,
  cumulativeAmount: parseUnits('40', 6),
  signature: '0x...',
})
// @log: true
```

### Standalone Action

```ts twoslash
import { parseUnits } from 'viem'
import { Actions } from 'viem/tempo'
import { client, channel } from './viem.config'

const valid = await Actions.channel.verifyVoucher(client, {
  channel,
  cumulativeAmount: parseUnits('40', 6),
  signature: '0x...',
})
```

## Return Value

`boolean`

Whether the signature is a valid voucher for the channel and amount.

Throws `ChannelNotFoundError` when the channel does not exist.

## Parameters

### channel

- **Type:** `Channel.from.Value`

Channel descriptor. The precompile computes the channel ID from it, so a channel ID alone is not enough.

### cumulativeAmount

- **Type:** `bigint`

Total voucher amount signed for the channel.

### signature

- **Type:** `Hex`

Voucher signature, from [`channel.signVoucher`](/tempo/actions/channel.signVoucher).
