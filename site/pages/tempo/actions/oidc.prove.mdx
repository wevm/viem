# `oidc.prove`

Proves an OIDC sign-in and returns the credential that [`Account.fromZk`](/tempo/accounts/account.fromZk) signs with. [Learn more about OIDC signers](https://tips.sh/1130-1)

The ID token's nonce commits to an access key, so the credential can only authorize that key. The transport must reach a [Relay API](/tempo/guides/oidc/relay-api), a relay with the [`Relay.oidc`](/tempo/relay/plugins/oidc) plugin. See [Sign In with an Identity Provider](/tempo/guides/oidc/sign-in) for the full flow.

## Usage

:::code-group

```ts twoslash [example.ts]
import { Account, WebCryptoP256 } from 'viem/tempo'
import { client } from './viem.config'

// Signs the user in with Google and returns the ID token for `nonce`.
declare function signInWithGoogle(options: { nonce: string }): Promise<string>

const keyPair = await WebCryptoP256.createKeyPair()

const { credential } = await client.oidc.prove({
  getToken: ({ nonce }) => signInWithGoogle({ nonce }),
  publicKey: keyPair.publicKey,
})

const account = Account.fromZk(credential)

console.log('Address:', account.address)
// @log: Address: 0xada6063F1Aade8B2516566A2a7e77d214b7f34f9
```

```ts twoslash [viem.config.ts (Remote Relay)] filename="viem.config.ts"
// [!include ~/snippets/tempo/oidc.config.ts:remote]
```

```ts twoslash [viem.config.ts (Local Relay)] filename="viem.local.config.ts"
// [!include ~/snippets/tempo/oidc.config.ts:local]
```

:::

Then authorize the access key with [`Account.fromZk`](/tempo/accounts/account.fromZk#usage) and attach the key authorization to its first transaction.

### Standalone Action

Call the action from `Actions` to pass the Client explicitly.

```ts twoslash
import { Actions, WebCryptoP256 } from 'viem/tempo'
import { client } from './viem.config'

declare function signInWithGoogle(options: { nonce: string }): Promise<string>

const keyPair = await WebCryptoP256.createKeyPair()

const { credential } = await Actions.oidc.prove(client, {
  getToken: ({ nonce }) => signInWithGoogle({ nonce }),
  publicKey: keyPair.publicKey,
})
```

## Recipes

These recipes assume your client connects to a [Relay API](/tempo/guides/oidc/relay-api).

### Sign In with a Redirect

Pages that redirect to the identity provider lose their state. Prepare the sign-in with `Oidc.prepare`, keep the result across the redirect, then pass it with the returned token.

```ts twoslash
import { Oidc, WebCryptoP256 } from 'viem/tempo'
import { client } from './viem.config'

// Before the redirect: create the access key, then request the ID token with `prepared.nonce`.
const keyPair = await WebCryptoP256.createKeyPair()
const prepared = Oidc.prepare({ publicKey: keyPair.publicKey }) // [!code focus]
sessionStorage.setItem('sign-in', JSON.stringify(prepared))

// After the redirect: prove with the token the identity provider returned.
declare const token: string
const { credential } = await client.oidc.prove({ ...prepared, token }) // [!code focus]
```

Keep `keyPair` in IndexedDB, where its private key stays non-extractable, and authorize it with [`Account.fromWebCryptoP256`](/tempo/accounts/account.fromWebCryptoP256). The relay only sees the key's address. See [Sign In with a Redirect](/tempo/guides/oidc/sign-in#sign-in-with-a-redirect) for the complete flow.

### Choose the Expiry

A credential stays valid for at most 600 seconds after the token was issued. Pass `validUntil` to shorten it.

```ts twoslash
import { WebCryptoP256 } from 'viem/tempo'
import { client } from './viem.config'

declare function signInWithGoogle(options: { nonce: string }): Promise<string>

const keyPair = await WebCryptoP256.createKeyPair()

const { credential } = await client.oidc.prove({
  getToken: ({ nonce }) => signInWithGoogle({ nonce }),
  publicKey: keyPair.publicKey,
  validUntil: Math.floor(Date.now() / 1000) + 120, // [!code focus]
})
```

### Reuse the Sign-In

`prove` also returns the nonce and the ID token, so the same sign-in can start a session with
your auth server. For example, [Better Auth](https://www.better-auth.com) verifies a Google ID
token and its nonce with `signIn.social`.

```ts twoslash
import { WebCryptoP256 } from 'viem/tempo'
import { client } from './viem.config'

declare function signInWithGoogle(options: { nonce: string }): Promise<string>
// A Better Auth client, from `createAuthClient`.
declare const authClient: {
  signIn: {
    social(options: {
      idToken: { nonce: string; token: string }
      provider: 'google'
    }): Promise<unknown>
  }
}

const keyPair = await WebCryptoP256.createKeyPair()

const { credential, nonce, token } = await client.oidc.prove({ // [!code focus]
  getToken: ({ nonce }) => signInWithGoogle({ nonce }),
  publicKey: keyPair.publicKey,
})

await authClient.signIn.social({ // [!code focus]
  idToken: { nonce, token }, // [!code focus]
  provider: 'google', // [!code focus]
}) // [!code focus]
```

Better Auth requires an `email` claim, so request the `email` scope along with `openid`.

## Return Value

`{ credential: ZkSignature.Credential; nonce: string; token: string }`

The credential to pass to [`Account.fromZk`](/tempo/accounts/account.fromZk), with the nonce the
ID token was requested with and the ID token it proves.

## Parameters

Pass either the fields `Oidc.prepare` returns with the ID token, or `getToken` with the access key's public key.

### accessKeyAddress

- **Type:** `Address`

Address of the access key the nonce commits to, from `Oidc.prepare`.

```ts twoslash
import { client } from './viem.config'
declare const prepared: { accessKeyAddress: `0x${string}`; blinding: `0x${string}`; validUntil: number }
declare const token: string
// ---cut---
const { credential } = await client.oidc.prove({
  accessKeyAddress: prepared.accessKeyAddress, // [!code focus]
  blinding: prepared.blinding,
  token,
  validUntil: prepared.validUntil,
})
```

### blinding

- **Type:** `Hex`

Blinding value the nonce commits to, from `Oidc.prepare`. Keep it private.

```ts twoslash
import { client } from './viem.config'
declare const prepared: { accessKeyAddress: `0x${string}`; blinding: `0x${string}`; validUntil: number }
declare const token: string
// ---cut---
const { credential } = await client.oidc.prove({
  accessKeyAddress: prepared.accessKeyAddress,
  blinding: prepared.blinding, // [!code focus]
  token,
  validUntil: prepared.validUntil,
})
```

### getToken

- **Type:** `(parameters: { nonce: string }) => string | Promise<string>`

Signs in with the nonce and returns the ID token. `prove` prepares the nonce for `publicKey` first.

```ts twoslash
import { WebCryptoP256 } from 'viem/tempo'
import { client } from './viem.config'
declare function signInWithGoogle(options: { nonce: string }): Promise<string>
const keyPair = await WebCryptoP256.createKeyPair()
// ---cut---
const { credential } = await client.oidc.prove({
  getToken: ({ nonce }) => signInWithGoogle({ nonce }), // [!code focus]
  publicKey: keyPair.publicKey,
})
```

### publicKey

- **Type:** `Hex | PublicKey`

Public key of the access key the credential will commit to.

```ts twoslash
import { WebCryptoP256 } from 'viem/tempo'
import { client } from './viem.config'
declare function signInWithGoogle(options: { nonce: string }): Promise<string>
const keyPair = await WebCryptoP256.createKeyPair()
// ---cut---
const { credential } = await client.oidc.prove({
  getToken: ({ nonce }) => signInWithGoogle({ nonce }),
  publicKey: keyPair.publicKey, // [!code focus]
})
```

### token

- **Type:** `string`

ID token the identity provider returned for the nonce.

```ts twoslash
import { client } from './viem.config'
declare const prepared: { accessKeyAddress: `0x${string}`; blinding: `0x${string}`; validUntil: number }
declare const token: string
// ---cut---
const { credential } = await client.oidc.prove({
  accessKeyAddress: prepared.accessKeyAddress,
  blinding: prepared.blinding,
  token, // [!code focus]
  validUntil: prepared.validUntil,
})
```

### validUntil

- **Type:** `number`
- **Default:** 540 seconds from now, with `getToken`

When the credential expires, in seconds. With the prepared fields, pass `Oidc.prepare`'s value.

```ts twoslash
import { WebCryptoP256 } from 'viem/tempo'
import { client } from './viem.config'
declare function signInWithGoogle(options: { nonce: string }): Promise<string>
const keyPair = await WebCryptoP256.createKeyPair()
// ---cut---
const { credential } = await client.oidc.prove({
  getToken: ({ nonce }) => signInWithGoogle({ nonce }),
  publicKey: keyPair.publicKey,
  validUntil: Math.floor(Date.now() / 1000) + 120, // [!code focus]
})
```

## Errors

| Error | Description |
| --- | --- |
| `InvalidParamsRpcError` | The request parameters are malformed. |
| `InvalidInputRpcError` | The relay rejected the ID token, or the prover cannot prove it. |
| `ResourceUnavailableRpcError` | The prover is busy or starting. Retry the request. |
| `InternalRpcError` | The relay could not reach the issuer's keys or the prover. |
