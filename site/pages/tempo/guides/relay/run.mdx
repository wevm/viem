# Run a Relay

## Overview

Use [`Relay.create`](/tempo/utilities/Relay.create) to expose Tempo RPC over the
Fetch API. The application hosts the endpoint and supplies its upstream client.
Add [`Relay.multisig`](/tempo/relay/plugins/multisig) for approval coordination.

## Recipes

These recipes assume you have [set up a Tempo client](/tempo).

### Use a Server Framework

Use the tab for your runtime or framework.
Node.js and Express need a Fetch-to-Node adapter, such as
`@remix-run/node-fetch-server`, installed in the hosting application.

:::code-group

```ts twoslash [Cloudflare Workers]
import { createClient, Relay } from 'viem/tempo'

const client = createClient()
const relay = Relay.create({
  client,
  plugins: [Relay.simulate(), Relay.feeToken()],
})

export default {
  fetch(request: Request) {
    return relay.fetch(request) // [!code focus]
  },
}
```

```ts [Bun]
import { createClient, Relay } from 'viem/tempo'

const client = createClient()
const relay = Relay.create({
  client,
  plugins: [Relay.simulate(), Relay.feeToken()],
})

Bun.serve({ fetch: relay.fetch })
```

```ts [Deno]
import { createClient, Relay } from 'viem/tempo'

const client = createClient()
const relay = Relay.create({
  client,
  plugins: [Relay.simulate(), Relay.feeToken()],
})

Deno.serve((request) => relay.fetch(request))
```

```ts [Node.js]
import { createServer } from 'node:http'
import { createRequestListener } from '@remix-run/node-fetch-server'
import { createClient, Relay } from 'viem/tempo'

const client = createClient()
const relay = Relay.create({
  client,
  plugins: [Relay.simulate(), Relay.feeToken()],
})

createServer(createRequestListener(relay.fetch)).listen(3000)
```

```ts [Express]
import { createRequestListener } from '@remix-run/node-fetch-server'
import express from 'express'
import { createClient, Relay } from 'viem/tempo'

const client = createClient()
const relay = Relay.create({
  client,
  plugins: [Relay.simulate(), Relay.feeToken()],
})

const app = express()
app.use('/relay', createRequestListener(relay.fetch))
app.listen(3000)
```

```ts [Hono]
import { Hono } from 'hono'
import { createClient, Relay } from 'viem/tempo'

const client = createClient()
const relay = Relay.create({
  client,
  plugins: [Relay.simulate(), Relay.feeToken()],
})

const app = new Hono()
app.post('/relay', (c) => relay.fetch(c.req.raw))
export default app
```

```ts [Elysia]
import { Elysia } from 'elysia'
import { createClient, Relay } from 'viem/tempo'

const client = createClient()
const relay = Relay.create({
  client,
  plugins: [Relay.simulate(), Relay.feeToken()],
})

new Elysia()
  .post('/relay', ({ request }) => relay.fetch(request), { parse: 'none' })
  .listen(3000)
```

```ts twoslash [Next.js]
import { createClient, Relay } from 'viem/tempo'

const client = createClient()
const relay = Relay.create({
  client,
  plugins: [Relay.simulate(), Relay.feeToken()],
})

export const POST = relay.fetch
```

:::

Mount the Node adapter before middleware that consumes the request body.
[Elysia disables its body parser](https://elysiajs.com/essential/life-cycle#skip-body-parsing)
with `parse: 'none'` so the relay can read the request. The
relay accepts JSON-RPC over `POST` with `Content-Type: application/json`;
`GET` returns `405`. Apply CORS, preflight handling, and custom headers in your
framework or around the Fetch handler.

### Add Plugins

Pass plugins to `Relay.create` to add services to the relay. Requests enter plugins
in array order, and each plugin can handle the request or pass it to the next handler.
For example, add the multisig plugin to coordinate owner approvals:

```ts twoslash
import { createClient, http } from 'viem'
import { tempo } from 'viem/chains'
import { Relay, Store } from 'viem/tempo'

const relay = Relay.create({
  client: createClient({ chain: tempo, transport: http() }),
  plugins: [Relay.multisig({ store: Store.memory() })], // [!code focus]
})

export default { fetch: relay.fetch }
```

:::info
[Memory storage](/tempo/utilities/Store.memory) is suitable for local development.
Independent processes and Worker isolates must share a persistent
[atomic store](/tempo/utilities/Store) so they can read and update the same approvals.
:::

To enable sponsorship, Auto Swap, fee-token selection, and simulation together,
list those plugins explicitly. Add multisig when you also need approval coordination:

```ts twoslash
import { createClient, http } from 'viem'
import { privateKeyToAccount } from 'viem/accounts'
import { tempo } from 'viem/chains'
import { Relay, Store } from 'viem/tempo'

const relay = Relay.create({
  client: createClient({ chain: tempo, transport: http() }),
  plugins: [ // [!code focus]
    Relay.multisig({ store: Store.memory() }), // [!code focus]
    Relay.simulate(), // [!code focus]
    Relay.feePayer({ account: privateKeyToAccount('0x...') }), // [!code focus]
    Relay.autoSwap(), // [!code focus]
    Relay.feeToken(), // [!code focus]
  ], // [!code focus]
})
```

### Select a Chain for an Endpoint

```ts twoslash
import { createClientResolver, http } from 'viem'
import { tempo, tempoModerato } from 'viem/chains'
import { Relay } from 'viem/tempo'

const { getClient } = createClientResolver({
  chains: [tempo, tempoModerato],
  transport: ({ chainId }) => http(chainId === tempo.id
    ? 'https://rpc.tempo.xyz'
    : 'https://rpc.moderato.tempo.xyz'),
})
const relay = Relay.create({ getClient })

export default {
  fetch(request: Request) {
    const chainId = new URL(request.url).pathname === '/testnet'
      ? tempoModerato.id
      : tempo.id
    return relay.fetch(request, { chainId }) // [!code focus]
  },
}
```

### Inspect Incoming Requests

Use a custom plugin before the built-in plugins to log or validate each incoming
RPC request. Await asynchronous checks before forwarding to `next`.

```ts twoslash
import { createClient, Relay } from 'viem/tempo'

const client = createClient()
const relay = Relay.create({
  client,
  plugins: [
    (next) => async (request, options) => { // [!code focus]
      console.log('Processing request:', request.method) // [!code focus]
      return next(request, options) // [!code focus]
    }, // [!code focus]
    Relay.simulate(),
    Relay.feeToken(),
  ],
})

export default { fetch: relay.fetch }
```

## Best Practices

Enforce authentication, request limits, and CORS in the hosting application.
Use an upstream execution client, rather than a client pointing back to the same
relay. Independent relay instances must use the same atomic storage.
