# Funding

## Overview

Funding requirements let a transaction use tokens or Earn shares to supply the balance its calls need. You can select sources directly or discover available sources before sending the transaction.

:::warning
**Experimental.** Transaction funding requires a TIP-1120-enabled node.
:::
