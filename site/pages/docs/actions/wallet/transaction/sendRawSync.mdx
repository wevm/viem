# sendRawSync

## Overview

Sends a **signed** serialized transaction to the network synchronously (`eth_sendRawTransactionSync`), and returns the transaction receipt.

## Recipes

### Reject a Reverted Receipt

Set `throwOnReceiptRevert` when a reverted receipt must reject instead of returning normally.

:::code-group

```ts twoslash [example.ts]
import { Hex } from 'viem/utils'
import { client } from './viem.config'

export function sendChecked(transaction: Hex.Hex) {
  return client.transaction.sendRawSync({
    throwOnReceiptRevert: true, // [!code focus]
    transaction,
  })
}
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
import { Client, http, walletActions } from 'viem'
import { mainnet } from 'viem/chains'

export const client = Client.create({
  chain: mainnet,
  transport: http(),
}).extend(walletActions())
```

:::

### Cancel or Time Out the Request

Pass an abort signal to cancel the transport request. The `timeout` value limits how long the node
waits before returning from `eth_sendRawTransactionSync`.

:::code-group

```ts twoslash [example.ts]
import { Hex } from 'viem/utils'
import { client } from './viem.config'

export function sendWithinDeadline(
  transaction: Hex.Hex,
  signal: AbortSignal,
) {
  return client.transaction.sendRawSync({
    requestOptions: { signal }, // [!code focus]
    timeout: 30_000, // [!code focus]
    transaction,
  })
}
```


## `Actions.transaction.sendRawSync`

Sends a **signed** serialized transaction to the network synchronously (`eth_sendRawTransactionSync`), and returns the transaction receipt.

### Usage

Call [`Actions.transaction.sendRawSync`](#actionstransactionsendrawsync) directly by passing the Client as the first argument.

:::code-group

```ts twoslash [example.ts]
import { Actions } from 'viem'
import { client } from './viem.config'

const receipt = await Actions.transaction.sendRawSync(client, {
  transaction: '0x02f850018203118080825208808080c080a04012522854168b27e5dc3d5839bab5e6b39e1a0ffd343901ce1622e3d64b48f1a04e00902ae0502c4728cbf12156290df99c3ed7de85b1dbfe20b5c36931733a33',
})
// @log: {
// @log:   status: 'success',
// @log:   transactionHash: '0x...',
// @log: }
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
import { Client, http } from 'viem'
import { mainnet } from 'viem/chains'

export const client = Client.create({
  chain: mainnet,
  transport: http(),
})
```

:::

### Parameters

#### options.requestOptions

- **Type:** `{ dedupe?: boolean; signal?: AbortSignal; ... }`

Per-request transport options forwarded to the `eth_sendRawTransactionSync` request.

```ts twoslash
import { Actions } from 'viem'
// [!include ~/snippets/docs/reference-client.ts:setup]
// ---cut---
const receipt = await Actions.transaction.sendRawSync(client, {
  requestOptions: { signal: AbortSignal.timeout(5_000) }, // [!code focus]
  transaction: '0x02f850018203118080825208808080c080a04012522854168b27e5dc3d5839bab5e6b39e1a0ffd343901ce1622e3d64b48f1a04e00902ae0502c4728cbf12156290df99c3ed7de85b1dbfe20b5c36931733a33',
})
```

#### options.throwOnReceiptRevert

- **Type:** `boolean`

Whether to throw if the returned receipt status is `reverted`.

```ts twoslash
import { Actions } from 'viem'
// [!include ~/snippets/docs/reference-client.ts:setup]
// ---cut---
const receipt = await Actions.transaction.sendRawSync(client, {
  throwOnReceiptRevert: true, // [!code focus]

})
```

#### options.timeout

- **Type:** `number`

Timeout, in milliseconds, for the sync RPC response.

### Return Value

`TransactionReceipt`

The transaction receipt.

### Errors

| Error | Description |
| --- | --- |
| `Actions.transaction.Errors.TransactionReceiptRevertedError` | The transaction receipt status was `reverted` and `throwOnReceiptRevert` was enabled. |
