# getGasPrice

## Overview

Returns the current price of gas (in wei).

## Recipes

### Read the Gas Price

Returns the current price of gas (in wei).

:::code-group

```ts twoslash [example.ts]
import { client } from './viem.config'

const gasPrice = await client.fee.getGasPrice() // [!code focus]
// @log: 2000000000n
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
import { Client, http, publicActions } from 'viem'
import { mainnet } from 'viem/chains'

export const client = Client.create({
  chain: mainnet,
  transport: http(),
}).extend(publicActions())
```

:::

## `Actions.fee.getGasPrice`

Returns the current price of gas (in wei).

### Usage

Call [`Actions.fee.getGasPrice`](#actionsfeegetgasprice) directly by passing the Client as the first argument.

:::code-group

```ts twoslash [example.ts]
import { Actions } from 'viem'
import { client } from './viem.config'

const gasPrice = await Actions.fee.getGasPrice(client)
// @log: 2000000000n
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
import { Client, http } from 'viem'
import { mainnet } from 'viem/chains'

export const client = Client.create({
  chain: mainnet,
  transport: http(),
})
```

:::

### Return Value

`bigint`

The current gas price, in wei.
