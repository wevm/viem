# getId

## Overview

Returns the chain ID associated with the current network.

## Recipes

### Read the Chain ID

Returns the chain ID associated with the current network.

:::code-group

```ts twoslash [example.ts]
import { client } from './viem.config'

const chainId = await client.chains.getId() // [!code focus]
// @log: 1
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
import { Client, http, publicActions } from 'viem'
import { mainnet } from 'viem/chains'

export const client = Client.create({
  chain: mainnet,
  transport: http(),
}).extend(publicActions())
```

:::

## `Actions.chains.getId`

Returns the chain ID associated with the current network.

### Usage

Call [`Actions.chains.getId`](#actionschainsgetid) directly by passing the Client as the first argument.

:::code-group

```ts twoslash [example.ts]
import { Actions } from 'viem'
import { client } from './viem.config'

const chainId = await Actions.chains.getId(client)
// @log: 1
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
import { Client, http } from 'viem'
import { mainnet } from 'viem/chains'

export const client = Client.create({
  chain: mainnet,
  transport: http(),
})
```

:::

### Return Value

`number`

The chain ID of the connected network.
