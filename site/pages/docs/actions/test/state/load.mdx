# load

## Overview

Adds state previously dumped with `dump` to the current chain.

## Recipes

### Load Node State


:::code-group

```ts twoslash [example.ts]
import { client } from './viem.config'

await client.state.load({ // [!code focus]
  state: '0x...', // [!code focus]
}) // [!code focus]
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
import { Client, http, testActions } from 'viem'
import { anvil } from 'viem/chains'

export const client = Client.create({
  chain: anvil,
  transport: http(),
}).extend(testActions())
```

:::

## `Actions.state.load`

Adds state previously dumped with `dump` to the current chain.

### Usage

Call [`Actions.state.load`](#actionsstateload) directly by passing the Client as the first argument.

:::code-group

```ts twoslash [example.ts]
import { Actions } from 'viem'
import { client } from './viem.config'

await Actions.state.load(client, {
  state: '0x...',
})
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
import { Client, http } from 'viem'
import { anvil } from 'viem/chains'

export const client = Client.create({
  chain: anvil,
  transport: http(),
})
```

:::

### Parameters

#### options

- **Type:** `Actions.state.load.Options`

The action options.

##### mode

- **Type:** `'anvil' | 'hardhat' | 'ganache'`
- **Default:** `'anvil'`

The test node implementation to target.

```ts twoslash
import { Actions, Client, http } from 'viem'
import { mainnet } from 'viem/chains'

const client = Client.create({
  chain: mainnet,
  transport: http(),
})
// ---cut---
await Actions.state.load(client, {
  state: '0x...',
  mode: 'hardhat', // [!code focus]
})
```

##### state

- **Type:** `Hex`

The state (from `dump`) to load.

```ts twoslash
import { Actions, Client, http } from 'viem'
import { mainnet } from 'viem/chains'

const client = Client.create({
  chain: mainnet,
  transport: http(),
})
// ---cut---
await Actions.state.load(client, {
  state: '0x...', // [!code focus]
  mode: 'hardhat',
})
```

### Return Value

`void`

No value is returned.
