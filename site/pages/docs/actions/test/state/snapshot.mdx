# snapshot

## Overview

Snapshots the state of the blockchain at the current block.

## Recipes

### Snapshot Node State


:::code-group

```ts twoslash [example.ts]
import { client } from './viem.config'

const result = await client.state.snapshot() // [!code focus]
// @log: '0x1'
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
import { Client, http, testActions } from 'viem'
import { anvil } from 'viem/chains'

export const client = Client.create({
  chain: anvil,
  transport: http(),
}).extend(testActions())
```

:::

## `Actions.state.snapshot`

Snapshots the state of the blockchain at the current block.

### Usage

Call [`Actions.state.snapshot`](#actionsstatesnapshot) directly by passing the Client as the first argument.

:::code-group

```ts twoslash [example.ts]
import { Actions } from 'viem'
import { client } from './viem.config'

const result = await Actions.state.snapshot(client)
// @log: '0x1'
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
import { Client, http } from 'viem'
import { anvil } from 'viem/chains'

export const client = Client.create({
  chain: anvil,
  transport: http(),
})
```

:::

### Return Value

`Hex`

The snapshot ID, which can be passed to `revert`.
