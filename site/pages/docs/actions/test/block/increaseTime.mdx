# increaseTime

## Overview

Jumps forward in time by the given amount of time, in seconds.

## Recipes

### Increase the Block Time


:::code-group

```ts twoslash [example.ts]
import { client } from './viem.config'

const result = await client.block.increaseTime({ // [!code focus]
  seconds: 420, // [!code focus]
}) // [!code focus]
// @log: '0x1'
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
import { Client, http, testActions } from 'viem'
import { anvil } from 'viem/chains'

export const client = Client.create({
  chain: anvil,
  transport: http(),
}).extend(testActions())
```

:::

## `Actions.block.increaseTime`

Jumps forward in time by the given amount of time, in seconds.

### Usage

Call [`Actions.block.increaseTime`](#actionsblockincreasetime) directly by passing the Client as the first argument.

:::code-group

```ts twoslash [example.ts]
import { Actions } from 'viem'
import { client } from './viem.config'

const result = await Actions.block.increaseTime(client, {
  seconds: 420,
})
// @log: '0x1'
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
import { Client, http } from 'viem'
import { anvil } from 'viem/chains'

export const client = Client.create({
  chain: anvil,
  transport: http(),
})
```

:::

### Parameters

#### options

- **Type:** `Actions.block.increaseTime.Options`

The action options.

##### seconds

- **Type:** `number`

The number of seconds to jump forward in time.

```ts twoslash
import { Actions, Client, http } from 'viem'
import { mainnet } from 'viem/chains'

const client = Client.create({
  chain: mainnet,
  transport: http(),
})
// ---cut---
const result = await Actions.block.increaseTime(client, {
  seconds: 420, // [!code focus]
})
```

### Return Value

`Hex`

The new total offset (in seconds) applied to the block timestamp.
