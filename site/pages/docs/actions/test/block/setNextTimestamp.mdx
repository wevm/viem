# setNextTimestamp

## Overview

Sets the next block's timestamp.

## Recipes

### Set the Next Block Timestamp


:::code-group

```ts twoslash [example.ts]
import { client } from './viem.config'

await client.block.setNextTimestamp({ // [!code focus]
  timestamp: 1_700_000_000n, // [!code focus]
}) // [!code focus]
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
import { Client, http, testActions } from 'viem'
import { anvil } from 'viem/chains'

export const client = Client.create({
  chain: anvil,
  transport: http(),
}).extend(testActions())
```

:::

## `Actions.block.setNextTimestamp`

Sets the next block's timestamp.

### Usage

Call [`Actions.block.setNextTimestamp`](#actionsblocksetnexttimestamp) directly by passing the Client as the first argument.

:::code-group

```ts twoslash [example.ts]
import { Actions } from 'viem'
import { client } from './viem.config'

await Actions.block.setNextTimestamp(client, {
  timestamp: 1_700_000_000n,
})
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
import { Client, http } from 'viem'
import { anvil } from 'viem/chains'

export const client = Client.create({
  chain: anvil,
  transport: http(),
})
```

:::

### Parameters

#### options

- **Type:** `Actions.block.setNextTimestamp.Options`

The action options.

##### timestamp

- **Type:** `bigint`

The timestamp (in seconds) to set.

```ts twoslash
import { Actions, Client, http } from 'viem'
import { mainnet } from 'viem/chains'

const client = Client.create({
  chain: mainnet,
  transport: http(),
})
// ---cut---
await Actions.block.setNextTimestamp(client, {
  timestamp: 1_700_000_000n, // [!code focus]
})
```

### Return Value

`void`

No value is returned.
