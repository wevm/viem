# removeTimestampInterval

## Overview

Removes the block timestamp interval set by `setTimestampInterval`, if it exists.

## Recipes

### Remove the Timestamp Interval


:::code-group

```ts twoslash [example.ts]
import { client } from './viem.config'

await client.block.removeTimestampInterval() // [!code focus]
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
import { Client, http, testActions } from 'viem'
import { anvil } from 'viem/chains'

export const client = Client.create({
  chain: anvil,
```

## `Actions.block.removeTimestampInterval`

Removes the block timestamp interval set by `setTimestampInterval`, if it exists.

### Usage

Call [`Actions.block.removeTimestampInterval`](#actionsblockremovetimestampinterval) directly by passing the Client as the first argument.

:::code-group

```ts twoslash [example.ts]
import { Actions } from 'viem'
import { client } from './viem.config'

await Actions.block.removeTimestampInterval(client)
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
import { Client, http } from 'viem'
import { anvil } from 'viem/chains'

export const client = Client.create({
  chain: anvil,
  transport: http(),
})
```

:::

### Parameters

#### options.mode

- **Type:** `'anvil' | 'hardhat' | 'ganache'`
- **Default:** `'anvil'`

The test node implementation to target.

```ts twoslash
import { Actions, Client, http } from 'viem'
import { mainnet } from 'viem/chains'

const client = Client.create({
  chain: mainnet,
  transport: http(),
})
// ---cut---
await Actions.block.removeTimestampInterval(client, {
  mode: 'hardhat', // [!code focus]
})
```

### Return Value

`void`

No value is returned.
