# Actions

## Overview

Actions perform JSON-RPC requests through a [Client](/docs/clients).
Each standalone action takes a Client as its first argument.

Decorators attach related actions to a Client as methods.
For example, [`publicActions`](/docs/actions/public) adds Public Actions through
[`.extend()`](/docs/clients/create#extending-a-client).

:::code-group

```ts twoslash [example.ts]
import { client } from './viem.config'

const blockNumber = await client.block.getNumber()
```

```ts twoslash [viem.config.ts] filename="viem.config.ts"
import { Client, http, publicActions } from 'viem'
import { mainnet } from 'viem/chains'

export const client = Client.create({
  chain: mainnet,
  transport: http(),
}).extend(publicActions())
```

:::
