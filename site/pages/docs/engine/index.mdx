# Engine

## Overview

The **Engine** module configures the cryptographic implementations used by Viem's
[cryptography utilities](/docs/utilities/hash). Viem uses portable JavaScript implementations by
default. An Engine can replace individual primitives with WebAssembly, Node.js, or custom
implementations without changing the utility APIs that call them.

Engine slots are partial. An omitted slot or primitive keeps its current override, or uses Viem's
default when no override is installed. The registry belongs to the loaded Ox module instance behind
Viem and is resolved when a cryptographic function is called.

| Entrypoint | Behavior |
| --- | --- |
| `viem` | Manages custom or prepared Engines. [`Engine.install`](/docs/engine/install) accepts an Engine value. |
| `viem/wasm` | Compiles and installs every WebAssembly implementation supplied by the entrypoint. |
| `viem/node` | Installs every `node:crypto` implementation supplied by the entrypoint. |

```ts twoslash
import { Engine } from 'viem/wasm'
import { Hash } from 'viem/utils'

await Engine.install()

const digest = Hash.sha256('0xdeadbeef')
// @log: '0x5f78c33274e43fa9de5659265c1d917e25c03722dcb0b8d27db8d5feaa813953'
```
