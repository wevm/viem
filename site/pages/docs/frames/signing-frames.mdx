# Signing Frames

## Overview

Prepare the transaction before requesting signatures. Preparation resolves helpers and fills gas budgets, nonce, and fees without invoking signing callbacks. Signing callbacks then receive the final transaction signing hash.

## Recipes

### Sign and Submit

[`signTransaction`](/docs/actions/wallet/signTransaction) invokes each frame's signing callbacks and returns the serialized transaction. Submit it with [`sendRawTransactionSync`](/docs/actions/wallet/sendRawTransactionSync).

:::code-group

```ts twoslash [example.ts]
import { calls } from 'viem/frames'
import { client } from './viem.config'

const request = await client.prepareTransactionRequest({
  frames: [calls([{ to: client.account.address, value: 1n }])],
})
const serializedTransaction = await client.signTransaction(request) // [!code focus]
const receipt = await client.sendRawTransactionSync({ serializedTransaction }) // [!code focus]
```

:::

### Sign a Frame Explicitly

Use [`Frame.sign`](/docs/frames/sign) to sign one frame before the final transaction signing call. Select the resolved frame from the prepared request, then replace that frame with the signed result. Keep the prepared transaction context. Completed signature slots are preserved.

:::code-group

```ts twoslash [example.ts]
import { calls, Frame } from 'viem/frames'
import { client } from './viem.config'

const request = await client.prepareTransactionRequest({
  frames: [calls([{ to: client.account.address, value: 1n }])],
})
const signed = await Frame.sign(request.frames[0]!, { transaction: request }) // [!code focus]
const serializedTransaction = await client.signTransaction({ // [!code focus]
  ...request, // [!code focus]
  frames: [signed, ...request.frames.slice(1)], // [!code focus]
}) // [!code focus]
```


:::

## Best Practices

Finalize all participants and transaction fields before signing. Modifying the transaction after a frame is signed causes Viem to reject it. Prepared helpers retain local signing callbacks and are not a JSON transport format.
