# Frame Transactions

## Overview

Frame Transactions (EIP-8141) bring native account abstraction to Ethereum. They let an
account define how a transaction is authorized and allow another account to pay its fees.
This supports custom wallet permissions and sponsored transactions within Ethereum's
transaction format.

A frame is one step in a transaction. Frames run in order to verify authorization, approve
gas payment, and execute calls. You can combine several contract interactions in one
transaction and group dependent calls so they either all succeed or revert together.
